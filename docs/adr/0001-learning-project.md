# Board Keeper is a learning project first

Board Keeper exists mainly to practise frameworks the author is less familiar with: React and Tailwind on the frontend, Spring Security and Spring Modulith on the backend, and more jOOQ. Being a useful score keeper comes second. Where a simpler option would do for a single household, we may still pick the one that exercises a learning target. A reader who finds, say, a modular monolith around a handful of tables should treat it as deliberate, not as over-engineering to remove.
