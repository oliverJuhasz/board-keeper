# Board Keeper is licensed under the AGPL, version 3 or later

Board Keeper is free software under the GNU Affero General Public License, version 3 or any later version (`AGPL-3.0-or-later`). Anyone may use, change and share it, also for money, but whoever shares a copy, or runs a changed copy for others over a network, must offer its source under the same licence. A permissive licence such as Apache 2.0 would have allowed a closed, changed copy to be run for others. A source-available licence such as the Functional Source License would have forbidden paid hosting altogether, but Board Keeper would no longer be open source. The AGPL keeps it open source, and keeps open every copy that others use.

## Consequences

- The application offers its own source: the About page, opened from the account menu, links to the commit the running version was built from. A changed copy points the links there at its own code.
- Game Modules run inside the application, so a module added to a copy is part of it and falls under the AGPL too.
- Contributions come in under the same licence, so changing the licence later needs the agreement of everyone who contributed.
